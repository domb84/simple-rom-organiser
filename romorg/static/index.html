3 Build library

One action tidies the whole folder: files are renamed and sorted, unwanted and duplicate files are set aside in their own folders (_excluded/, _superseded/, _duplicates/ ...; never deleted), and playlists are written for complete multi-disk games. Preview first; Undo last reverts everything, playlists included.

      Organise only renames: a SNES dump with a 512-byte copier header stays .smc and a
        byte-swapped N64 dump stays .v64 / .n64. Converting writes a clean copy exactly as
        listed in the DAT (headerless .sfc, big-endian .z64) and moves the original to
        _converted_originals/ - nothing is deleted, and Undo last reverts it.
        Single-file .zip archives are converted into a new .zip; extract .7z files first.
