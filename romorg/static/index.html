    Disc images (CHD)

    Settings for every system that uses CHD files: Dreamcast, PlayStation, PlayStation 2. Turning raw discs into CHDs is the Convert option of a system's Library tab.

    Reading and writing CHDs

      libFLAC was not found, so the built-in writer stores audio tracks with LZMA instead of FLAC: the CHDs are valid and verified, but discs with audio tracks come out larger than chdman's.
      Zstandard CHDs are not read by older emulators and some RetroArch cores. Convert one game and load it in your emulators before converting a collection.
      identified: every data track matches Redump, audio tracks have the right length · verified: every track (audio too) was decoded and equals Redump · raw: an unpacked Redump set (.gdi / .cue + tracks, or an .iso): convert it to a CHD with the Library tab's Convert option.

      Shared folders

      Assets you keep outside RetroArch (playlists, thumbnails, cheats, remaps ...). For each setting the app finds the folder of that name inside the folder below and shows whether RetroArch already uses it. Nothing is moved: only the setting changes.

      UseSettingRetroArch uses nowShared folderState

      Saves follow the games

      RetroArch finds a save by the game's file name. A build in place renames the saves; a build into another folder copies them to the new names. Each core's folder stays separate, and nothing is overwritten. Undoing the build gives the old names back. It waits if RetroArch is running.

      BIOS, firmware and key files

      Checks the BIOS and firmware files that your installed cores list against RetroArch's system folder, verified by checksum where the core gives one. Missing ones are looked for in the ROM folders of the systems you have set up (and the and any folder you add). Choose one system to limit it. The key files the Switch and Wii U emulators need (prod.keys, title.keys for Eden and Ryujinx, keys.txt for Cemu) are checked and looked for the same way; a key file found is always copied into place, never moved.
