Simple ROM Organiser - third-party notices
==========================================

Simple ROM Organiser itself needs nothing but Python's standard library. The Windows packages can carry, or can
use if you provide them, the programs below. They are separate programs / libraries with their own licences.

audio tracks are then stored with LZMA (valid, but larger) and decoded more slowly.

libzstd (bundled in the Linux AppImage only, not in the Windows packages)
-----------------------------------------------------------------------
Used to decode and encode Zstandard (CHD zstd / cdzs hunks, the Zstandard writer preset, RVZ groups) where Python
has no Zstandard of its own (romorg/zstdnative.py). The Windows packages use Python 3.14's compression.zstd and ship
no libzstd.

  * libzstd 1.5.7, the unmodified libzstd.so.1.5.7 of the Arch Linux package zstd-1.5.7-3 (SHA-256 of the package
    d4cf0049137124c8a025eedfad267a3e8a02310c9efb9d1ae4a61aa1d02789fc). Copyright (c) Meta Platforms, Inc. and
    affiliates. zstd is dual licensed under the BSD 3-clause licence or GPL-2.0; it is used here under the BSD
    3-clause licence, reproduced in licenses/zstd/LICENSE inside the AppImage.
  * Source code: https://github.com/facebook/zstd (tag v1.5.7).

libsndfile (bundled in the Windows .zip package, in the "native" folder)
-----------------------------------------------------------------------
Used (optionally) to decode the FLAC audio inside CD-image CHD files quickly (romorg/nativeflac.py) when libFLAC
cannot be loaded. If the file is absent or cannot be loaded the program still works.

  * libsndfile is licensed under the GNU Lesser General Public License, version 2.1 or later (see
    licenses\libsndfile-COPYING.txt). Copyright (C) Erik de Castro Lopo and contributors.
  * It contains libFLAC and other libraries (Ogg, Vorbis, Opus, LAME, mpg123 ...) under their own licences; their
    copyrights and source locations are listed in licenses\libsndfile-license_notes.md.
  * Source code: https://github.com/libsndfile/libsndfile  (the DLL is the unmodified build distributed in the
    "soundfile" wheel on PyPI, https://github.com/bastibe/python-soundfile).
  * It is loaded dynamically (ctypes) and is NOT linked into the program. You may replace
    native\libsndfile-1.dll with your own build of libsndfile, or delete it, and the program keeps working.
    (The single-file .exe, if built with -BundleSndfile, carries the DLL inside; use the .zip package to replace it.)

chdman (NOT bundled)
--------------------
The program reads and writes CHD files itself; chdman from MAME (https://www.mamedev.org/) is optional and not
included. If you want to use it, take chdman.exe from the MAME download at mamedev.org and put it on your PATH,
next to the program (the .exe, or the top folder of the .zip package), or in a common MAME folder: it is found
automatically and can be chosen in the Convert step. You can also enter its path in the Convert step.
MAME is made available under the GNU General Public License; MAME is a registered trademark of Gregory Ember.
This project is not affiliated with or endorsed by the MAME team.

7-Zip (NOT bundled)
-------------------
.rar and unusual .7z archives are read with 7-Zip (https://www.7-zip.org/), if installed. 7-Zip is under the GNU
LGPL (with an unRAR restriction); it is not included.

Python
------
The .zip package contains the unmodified "embeddable" Python 3.14 distribution from https://www.python.org/ (PSF
licence, see licenses\python-LICENSE.txt, which also carries the licences of libraries it contains, such as
Zstandard, bzip2 and libffi); the single-file .exe is built from Python 3.14 with PyInstaller 6.22.3 (GPL-2.0 with the
bootloader exception, which allows any licence for the resulting program).
