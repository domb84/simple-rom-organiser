Simple ROM Organiser - third-party notices
==========================================

Simple ROM Organiser itself needs nothing but Python's standard library. It can use, if you provide them, the
programs below. They are separate programs / libraries with their own licences. What the AppImage ships is listed
in docs/THIRD_PARTY.md (licenses/THIRD_PARTY.md inside the image).

libzstd (bundled in the Linux AppImage)
---------------------------------------
Used to decode and encode Zstandard (CHD zstd / cdzs hunks, the Zstandard writer preset, RVZ groups) where Python
has no Zstandard of its own (romorg/zstdnative.py).

  * libzstd 1.5.7, the unmodified libzstd.so.1.5.7 of the Arch Linux package zstd-1.5.7-3 (SHA-256 of the package
    d4cf0049137124c8a025eedfad267a3e8a02310c9efb9d1ae4a61aa1d02789fc). Copyright (c) Meta Platforms, Inc. and
    affiliates. zstd is dual licensed under the BSD 3-clause licence or GPL-2.0; it is used here under the BSD
    3-clause licence, reproduced in licenses/zstd/LICENSE inside the AppImage.
  * Source code: https://github.com/facebook/zstd (tag v1.5.7).

chdman (NOT bundled)
--------------------
The program reads and writes CHD files itself; chdman from MAME (https://www.mamedev.org/) is optional and not
included. If you want to use it, install MAME's chdman: it is found automatically on your PATH (or in the Flatpak
org.mamedev.MAME) and can be chosen in Settings > Disc images. You can also enter its path there.
MAME is made available under the GNU General Public License; MAME is a registered trademark of Gregory Ember.
This project is not affiliated with or endorsed by the MAME team.

7-Zip (NOT bundled)
-------------------
.rar and unusual .7z archives are read with 7-Zip (https://www.7-zip.org/), if installed. 7-Zip is under the GNU
LGPL (with an unRAR restriction); it is not included.


BIOS / firmware list (bundled as data: romorg/biosdata.py)
----------------------------------------------------------
The names and checksums of the BIOS, firmware and system files that emulators need are taken from "System.dat" of the
libretro-database project (https://github.com/libretro/libretro-database/blob/master/dat/System.dat, version v1.19.0),
which is under the Creative Commons Attribution-ShareAlike 4.0 licence (https://creativecommons.org/licenses/by-sa/4.0/).
The list is reproduced as data (system, file name, size, CRC-32, SHA-1) and stays under that licence. No BIOS or
firmware file itself is included.
